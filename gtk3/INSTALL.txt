GTK 3 bounce scrolling for Debian 13 (trixie) / GNOME 48
====================================================

This bundle replaces native system GTK 3 packages with
3.24.49-3+bounce1, based on Debian's exact 3.24.49-3
source plus the GTK 3 bounce port. Compilation and regression testing
happen in GitHub Actions. The amd64 bundle includes i386 packages. The
arm64 bundle includes native ARM64 packages.

From this extracted directory, preview the APT transaction:
  bash install.sh --dry-run

Install:
  bash install.sh

The helper verifies checksums, OS, architecture and installed package
versions. It selects only matching GTK 3 packages already installed on your
machine and uses apt-get --no-remove. It asks for
sudo and shows APT's transaction for you to confirm.

Log out and back in, or reboot, so applications load the new GTK library.

Rollback to the original Debian packages bundled here:
  bash rollback.sh
This permits the expected version downgrade and likewise refuses removals.

No package holds or APT pins are created. A later Debian package revision
supersedes this custom version normally. Rebuild against updated Debian
sources to retain the effect.

This changes native system GTK 3 applications. Flatpak and Snap runtimes
have their own libraries and are independent of the system replacement.

provenance/build.json identifies the CI commit, run and test coverage.
The full display/GPU/accessibility test matrix and physical touchpad feel
are outside the automated regression checks.
